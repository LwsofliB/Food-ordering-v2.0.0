# Food-ordering-v2.0.0
点餐小程序模拟v2.0.0（本地局域网版）
--新增了网页版本点餐
--添加了后厨看板功能，方便后厨进行备餐
--实现了多设备进行并发点餐（目前项目需要设备连接同一个网络）
--改善了订单日志的写入
--管理员功能也改成网页版了

点餐小程序模拟v2.0.0操作步骤：
--启动服务器：python server.py
--查看本机（服务器）局域网IP：ipconfig
--手机与服务器连接同一个WIFI，电脑测试打开网址：http://127.0.0.1:5000/order
--手机浏览器访问 http://你的IPv4地址:5000/order
--order是点餐页面，kitchen是后厨页面，admin是管理员页面
